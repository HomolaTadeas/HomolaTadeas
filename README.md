# SK Sigma Olomouc

SK Sigma Olomouc je český fotbalový klub
z Olomouce. Fotbal má v České republice
dlouhou tradici a Sigma patří mezi známé
moravské kluby.

## Stadion

Domácí prostředí je důležitou součástí
každého fotbalového klubu.

![Stadion Sigmy Olomouc](images/sigma-stadion.jpg)
