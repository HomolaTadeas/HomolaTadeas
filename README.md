# SK Sigma Olomouc

SK Sigma Olomouc je český fotbalový klub
z Olomouce. Fotbal má v České republice
dlouhou tradici a Sigma patří mezi známé
moravské kluby.

## Stadion

Domácí prostředí je důležitou součástí
každého fotbalového klubu.

## Český fotbal

Informace o českém fotbale najdeš
na [webu FAČR](https://www.fotbal.cz/).

Sigma Olomouc je **fotbalový klub**
s bohatou tradicí.

Fotbal je *týmový sport*, který spojuje hráče
i fanoušky.
